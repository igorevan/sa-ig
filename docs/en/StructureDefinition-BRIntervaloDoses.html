Extension: Intervalo de Doses

Official URL: http://www.saude.gov.br/fhir/r4/StructureDefinition/BRIntervaloDoses Version: 1.0.0-release
Standards status: Normative Maturity Level: 1 Computable Name: BRIntervaloDoses

Extensão para descrever uma unidade de tempo referenciada pelo UCUM.

Context of Use

    Esta extensão pode ser usada nos seguintes elementos

    • Element ID: MedicationRequest

Usage info
